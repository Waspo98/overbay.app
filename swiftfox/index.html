Why I built a 120Hz WebView browser

I wanted Zen Browser and Firefox's Spaces, sync, and ad-blocking tools on my foldable phone, without GeckoView's jittery scrolling text at 120Hz and without Chrome's stripped-down mobile controls.

Swiftfox builds on Android's system Chromium WebView for smooth scrolling and automatic Google Play engine security patches, while wrapping it in a Material 3 Compose shell tailored for folded one-handed use and unfolded wide-screen reading.

  • Independent folded & unfolded layouts

    Jetpack WindowManager tracks posture so folded cover screens and unfolded inner displays keep separate toolbar layouts (Top, Bottom, Split, or Side Rail), scroll-hiding settings, and Mobile vs. Desktop site defaults. Folding never reloads tabs or stops audio unless your site mode changes.

  • Zen Spaces, Essentials & isolated tabs

    Organize tabs into Spaces with pinned Essentials—a slide-over drawer and card switcher when folded, or a collapsible vertical sidebar when unfolded. Private tabs run in ephemeral ProfileStore sessions, with optional per-Space cookie containers.

  • Native adblock-rust & Element Zapper

    Embeds adblock-rust over JNI with EasyList, EasyPrivacy, uBlock Origin lists, and custom list URLs. When a sticky banner slips through, tap Element Zapper to hide it with undo or save a permanent per-site CSS rule using a parent/child scope slider.

  • Dark Reader, userscripts & Reader Mode

    Toggle web-content night mode independently using the bundled Dark Reader engine (with AMOLED #000000 and auto-skip for native dark sites), install .user.js scripts, set per-site overrides, or switch into Mozilla Readability Reader Mode.

Firefox & Zen Browser sync—and honest limits

Sign into your Mozilla Account in an isolated in-app view or scan a QR code from Desktop Firefox or Zen Browser to sync bookmarks, history, synced open tabs, and Zen Spaces, Essentials, and pinned items. Coming from Chrome? Import or export standard Netscape HTML bookmark files locally anytime.

Everyday features are built in too: a smart omnibox with Google default (plus DuckDuckGo, Kagi, Brave, Startpage, or custom search and !bang shortcuts), Picture-in-Picture and background audio playback, Blob downloads, Clean URL sharing, HTTPS-Only mode, and Android System Autofill.

Technical notes & honest limits

  • Sync: Two-way Firefox & Zen Browser sync via Mozilla Accounts (OAuth or QR pairing), plus local Chrome HTML bookmark import/export.
  • Extensions: Android WebView cannot run .crx Chrome or .xpi Firefox extensions—blocking and tweaks use adblock-rust, Element Zapper, Dark Reader, .user.js userscripts, and per-site rules instead.
  • Passwords: Uses Android System Autofill and Credential Manager rather than a separate built-in password vault.
  • Themes: Day, Dark, and true #000000 AMOLED chrome with Fox Amber, Midnight Indigo, Forest, Monochrome, or optional Material You colors.

Frequently asked questions

Why use Android WebView instead of GeckoView or Chromium source?

On 120Hz Android phones, GeckoView text scrolling often shows visible frame jitter compared to Chromium, while maintaining a full Chromium fork takes hundreds of gigabytes of C++ builds. Using Android's built-in Chromium WebView gives Swiftfox smooth 120Hz scrolling and automatic Google Play engine security updates while leaving me free to build the UI, ad blocker, Dark Reader, and sync layers in Kotlin.

Can Swiftfox install Chrome .crx or Firefox .xpi extensions?

No. Android WebView does not expose Chrome or Firefox extension APIs. Instead, Swiftfox builds the core tools I rely on right into the browser: native adblock-rust with EasyList and uBlock Origin lists, an interactive Element Zapper, bundled Dark Reader, per-site rules, and .user.js userscripts.

How does Firefox and Zen Browser sync work?

You can sign in with your Mozilla Account inside an isolated in-app login view or pair via QR code using Desktop Firefox or Zen Browser. Swiftfox syncs bookmarks, history, synced open tabs, and Zen Spaces, Essentials, and pinned tabs directly with Mozilla's Sync servers using Mozilla application-services.

Does folding or unfolding reload my open tabs?

No, unless your folded and unfolded profiles choose a different site mode for that page. Swiftfox handles configuration changes in place and keeps your warm WebView tab pool and playing media alive across posture changes.

How are passwords and autofill handled?

Swiftfox uses Android System Autofill and Credential Manager so your existing password manager or passkeys work naturally, instead of building a separate in-app password vault.

Does Swiftfox send my browsing history to Overbay.app?

No. I don't run any Swiftfox servers or analytics. Your tabs, Spaces, history, and rules stay on your phone—and if you enable Mozilla Sync, your device talks directly to Mozilla's servers.
