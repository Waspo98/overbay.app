Deploy in 60 Seconds

One Docker Compose file. One .env config. Pull and run — you're tracking finances in under a minute. Update with a single docker compose pull. Back up by snapshotting the Docker volume.

Up and Running in Seconds

All you need is Docker. Copy the env file, set your password, and go.

# Clone the repo
git clone https://github.com/Waspo98/Orbit-Money.git
cd Orbit-Money

# Configure your environment
cp .env.example .env

# Start Orbit Money
docker compose pull
docker compose up -d

# Open http://localhost:5008 🎉
