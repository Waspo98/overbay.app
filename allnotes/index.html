Why bounded pages instead of an infinite canvas

OneNote nailed hierarchy: Notebooks on the left, Sections across the top, Section Groups when projects grow, and Pages underneath. The part that breaks on phones and wide monitors alike is the freeform 2D text-box canvas where paragraphs clip off the side or overlap.

AllNotes keeps that notebook hierarchy and drops the 2D canvas. Every page renders in a fixed-width document column that fits comfortably on a phone screen and a desktop monitor without sideways scrolling.

  • Notebooks, Sections & Section Groups

    Organize larger projects with nested Section Groups while keeping top-level tabs fast to switch between.

  • Structured Content Blocks

    Write using headings, callout boxes, interactive checklists, tables, and monospace code blocks—all stored locally for offline reading and editing.

  • One Android Permission

    The Android package declares only the standard INTERNET permission, used when you point the app at a sync server URL. No access to contacts, location, camera, or microphone.

  • Local-First SQLDelight Storage

    Your workspace lives inside a local SQLite database managed by SQLDelight on your device. No account login is required to create, search, or edit notes.

Optional self-hosted Ktor sync

By default, AllNotes stays completely offline. When you want notes synced across devices, it is built to talk to your own self-hosted Ktor server rather than an Overbay cloud account.

Public Windows (x64 / ARM64) desktop packages and standalone server setup images will be published here once packaging wraps up.

Planned sync server options

  • Default port: PORT=8094 behind your reverse proxy with TLS.
  • Bearer auth: ALLNOTES_AUTH_TOKEN for direct token auth from clients.
  • Forward auth: TRUST_AUTHENTIK_HEADERS=true when sitting behind an Authentik OIDC proxy.
  • Release status: Android offline mode works today; desktop installers and public server packaging are in progress.

Frequently asked questions

Does AllNotes upload my notes to Overbay servers?

No. Overbay does not host note accounts or run analytics in AllNotes. Notes stay in local SQLite on your device unless you configure the URL and credentials for a sync server you host yourself.

Are stylus inking or infinite whiteboards supported?

No. AllNotes focuses on structured typography and bounded document pages so notes wrap properly on both phones and desktop monitors without awkward zooming.

When are the Windows installer and standalone sync server coming?

The Android preview APK is available to download now. Public Windows x64/ARM64 installers and the standalone Ktor sync server package will be linked here once packaging is ready.
