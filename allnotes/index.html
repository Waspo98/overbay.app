Why bounded pages instead of an infinite canvas

OneNote got hierarchy right: Notebooks on the left, Sections across the top, Section Groups when projects multiply, and Pages neatly nested underneath. What breaks on phones and ultrawide monitors alike is the freeform 2D text-box canvas where paragraphs clip off the right edge or overlap.

AllNotes keeps the notebook hierarchy and drops the 2D canvas. Every page uses a readable column width that works natively across phone touchscreens and desktop keyboards without pinching, panning, or stylus calibration.

  • Notebooks, Sections & Section Groups

    Organize deep projects naturally with nested Section Groups while keeping top-level tabs fast to scan.

  • Rich Structured Content Blocks

    Write using headings, callout boxes, interactive checklists, tables, and monospace code blocks — readable offline immediately.

  • Minimal Android Permission Surface

    The Android package declares only the INTERNET permission (used strictly if you point the app at your own sync URL). No contacts, location, camera, or microphone access.

  • Local-First SQLDelight Storage

    Your workspace lives directly inside a SQLite database managed by SQLDelight on your device. No mandatory cloud login is required to open, search, or edit notes.

Optional self-hosted Ktor sync

When you want notes synchronized across devices, AllNotes connects directly to your own self-hosted Ktor backend instead of an Overbay-operated cloud account. Configure a bearer token (ALLNOTES_AUTH_TOKEN) or reverse-proxy OIDC headers (TRUST_AUTHENTIK_HEADERS) behind TLS.

Public Windows (x64 / ARM64) desktop packages and standalone server setup images are planned once packaging stabilizes.

Self-hosted sync server endpoint contract 
# Example environment variables for AllNotes Ktor sync
PORT=8094
ALLNOTES_AUTH_TOKEN=replace-with-random-token
# Or authenticate behind Authentik forward-auth proxy:
TRUST_AUTHENTIK_HEADERS=false

Frequently asked questions

Does AllNotes upload my notes to Overbay servers?

No. Overbay does not host user note accounts or run analytics in AllNotes. Notes stay locally on your device unless you configure the URL and credentials for a sync server you operate yourself.

Are stylus inking or infinite whiteboards supported?

No. AllNotes focuses intentionally on structured typography and bounded Word-style document flow so every note renders cleanly on Android and desktop viewports.

How is the Windows build progressing?

The shared Kotlin codebase targets both x64 and ARM64 Windows MSI/EXE installers alongside the existing Android app. Installer links will be added here as soon as signed builds are published.
