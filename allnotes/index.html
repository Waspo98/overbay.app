Why normal pages instead of an endless canvas

OneNote got the hierarchy right: Notebooks on the left, Sections across the top, Section Groups when things grow, and Pages underneath. The part that always drove me crazy on phones and wide monitors is the freeform 2D text-box canvas where notes overlap or clip off the edge.

I built AllNotes to keep that notebook layout and drop the 2D canvas. Every page wraps cleanly to your screen width—comfortable on a phone and crisp on a monitor, with zero sideways scrolling.

  • Notebooks, Sections & Section Groups

    Organize bigger projects with nested section groups while keeping top-level tabs fast to switch between.

  • Clean formatting blocks

    Write with headings, callout boxes, interactive checklists, tables, and code blocks—all saved locally so they open instantly offline.

  • Just one permission

    Only asks for basic internet access (used if you connect a self-hosted sync server). Never asks for contacts, location, camera, or mic.

  • Offline first, no sign-in wall

    Your notes live in a local database right on your device. Open the app and start typing—no account needed.

Optional self-hosted sync

Out of the box, AllNotes stays completely offline. When cross-device sync ships, it will connect to a lightweight server you run yourself instead of a cloud account I host.

I'll link the Windows (x64 / ARM64) installers and standalone server package here once I finish packaging them.

Planned sync server options

  • Status: Android offline mode works today; desktop installers and server packaging are in progress.
  • Default port: Runs on PORT=8094 behind your reverse proxy with HTTPS.
  • Token auth: Direct access token (ALLNOTES_AUTH_TOKEN) from your clients.
  • Proxy login: Supports Authentik / OIDC forward-auth headers (TRUST_AUTHENTIK_HEADERS=true).

Frequently asked questions

How is AllNotes different from Microsoft OneNote?

AllNotes keeps OneNote's deep Notebook, Section Group, Section, and Page hierarchy, but replaces the freeform 2D text-box canvas with normal bounded pages that wrap cleanly on phones. It also works completely offline with no Microsoft account required, and will support optional self-hosted sync.

Does AllNotes upload my notes anywhere?

No. I don't host note accounts or run any tracking. Everything stays on your device unless you point the app at a sync server you host yourself.

Can I draw with a stylus or use an infinite whiteboard?

No. AllNotes is built for typed notes and normal pages that wrap cleanly on both phones and desktop monitors without awkward zooming.

When are the Windows app and sync server coming?

The Android APK is ready to download from GitHub Releases now. I'll link the Windows installers and self-hosted sync server package here as soon as I finish packaging them.
